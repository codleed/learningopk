# Auth Accent Green Design

**Date:** 2026-03-10

## Goal

Change the accent color on the standalone Bento auth screens from orange to lime green without affecting the rest of the app.

## Scope

- Update `/login` and `/register` only
- Keep existing layout, validation, fields, and auth flows unchanged
- Keep error styling as-is

## Visual Change

Replace the current auth-only orange accent usage with a lime-green palette across:

- primary buttons
- inline auth links
- checkbox accents
- select chevrons
- focus accent borders
- login badge tint
- top-right auth header link hover state

Neutral backgrounds, navy text, and non-auth pages remain unchanged.
