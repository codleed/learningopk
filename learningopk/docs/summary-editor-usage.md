# Chapter Summary Editor Usage Guide

## Wiki Links

- In the chapter summary editor, type `[[` to trigger chapter suggestions.
- Keep typing to filter suggestions.
- Click a suggestion chip to insert the link.
- Example: `[[Chapter 2: Kinematics]]`

## Backlinks and Unresolved Links

- Save the summary after editing.
- In the `Links` panel:
- `Outgoing` shows links from the current summary.
- `Backlinks` shows chapters that reference the current summary.
- Unresolved links are shown with `(unresolved)` so they can be fixed later.

## Graph View

- Open the `Summary Graph` panel in the chapter editor.
- Use the search input to filter by chapter title.
- Pan/zoom directly in the graph canvas.
- Click any graph node or chapter chip under `Open chapter` to load that chapter into the editor.
