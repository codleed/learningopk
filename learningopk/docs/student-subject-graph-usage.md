# Student Chapter Graph: Quick Usage Guide

## Where to find it

1. Sign in as a student.
2. Open any subject page, for example: `/fbise/9th/physics`.
3. In the `Chapters` section, click `Graph`.

## How to use it

1. Pan: click and drag on the graph canvas.
2. Zoom: use mouse wheel or trackpad pinch.
3. Search: use `Search chapters by title` to filter nodes.
4. Open chapter: click a graph node, or click a chapter button below the graph.

## What you will see

- Only published chapters from the current subject.
- Subject-only chapter links (no cross-subject nodes).
- Progress hints on node buttons:
  - `Visited`
  - `Completed`
