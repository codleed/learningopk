## Production Notes

- **Presenter:** If using an on-camera presenter, position webcam overlay in bottom-right corner (small, ~15% of screen). If voice-only, use cursor highlights and subtle zoom animations to guide viewer attention.
- **Pacing:** Cut any dead air. This should feel dense but not rushed. Transitions between sections should be clean — a quick wipe or a 0.5-second logo sting.
- **Music:** Background music should be present throughout but very subtle — instrumental, modern, upbeat but not distracting. Duck the music significantly (-18dB to -24dB) under voiceover.
- **Captions:** Burn in English subtitles for accessibility and for viewers watching without sound. Use a clean sans-serif font.
- **Screen recording:** Record at 1080p minimum. Use a clean browser with no visible bookmarks bar, no other tabs, no notifications. Dark mode or light mode — pick one and be consistent.
